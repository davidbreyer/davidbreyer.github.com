Lizard Tools

Small static browser tools for API payloads, structured data, duplicate hunting, and date-time glue work.

all local in the browser · no server-side processing

> tools --list

format compare mock duplicate datetime

# keep the payloads local

./toolbox

01 Format Lizard Format JSON, XML, YAML, and CSS in the browser. 02 Compare Lizard Compare JSON and XML payloads side by side. 03 Mock Lizard Generate realistic mock API data from sample JSON. 04 Duplicate Lizard Find repeated identifiers and duplicate-like XML entries. 05 DateTime Lizard Convert dates for .NET, SQL Server, LINQ, and API work.

./local

These tools are static pages. The work happens in your browser, and the apps are designed around copy, paste, open, save, and move on.
